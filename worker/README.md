# «Где поесть» — защищённый прокси (Cloudflare Worker)

Сайт KOYO RADAR работает на GitHub Pages, у которого нет сервера, а секретный ключ API нельзя класть в публичный JavaScript. Поэтому запросы к Google (и, по желанию, к Claude) идут через этот небольшой Worker. Ключи хранятся только в секретах Cloudflare.

```
iPhone (сайт) ──HTTPS──► Cloudflare Worker ──► Google Places API (New): поиск, детали, фото
                          (ключи, лимиты)   ──► Google Routes API: время пешком / на транспорте
                                            ──► Claude API (опционально, выключено по умолчанию)
```

## Какие сервисы нужны и сколько это может стоить

> Цены и бесплатные лимиты Google меняются. Ниже — ориентир по модели «бесплатный лимит на каждый SKU в месяц». Перед включением проверьте <https://developers.google.com/maps/billing-and-pricing/pricing> и <https://www.anthropic.com/pricing>.

| Что | Когда вызывается | Тариф Google (ориентир) | Комментарий |
|---|---|---|---|
| **Places API (New) — Text Search** | 4 запроса на поиск (район делится на 4 квадрата — так Google отдаёт заметно больше мест рядом); «🔎 Искать ещё» — ещё 3 (1 запрос × 3 страницы), затем ещё 4; не больше 11 за один поиск | SKU *Enterprise* (из-за полей рейтинга, числа отзывов, цены и часов): ~1 000 бесплатных запросов в месяц, дальше порядка $35 за 1 000 | Раньше был 1 запрос на поиск. Ручной ввод адреса добавляет ещё один дешёвый запрос (только координаты). Поля — минимальные, без отзывов |
| **Routes API — Compute Route Matrix** | 1 раз на поиск и на каждое «Искать ещё», ≤ 100 элементов | WALK — *Essentials*, TRANSIT — *Pro*; тысячи бесплатных элементов в месяц | Если Google не вернёт маршрут на транспорте (в Японии это возможно), сайт покажет расстояние и ссылку на Google Maps — без выдуманных минут |
| **Places API (New) — Place Details** с `reviews` и `reviewSummary` | Только по нажатию «✨ Выжимка», 1 раз на место за сессию | SKU *Enterprise + Atmosphere*: ~1 000 бесплатных в месяц, дальше порядка $25 за 1 000 | Google отдаёт не больше 5 отзывов на место |
| **Place Photos** | Только если включены миниатюры (по умолчанию выключены) | Отдельный SKU, примерно 1 000 бесплатных в месяц | Одна миниатюра = один запрос |
| **Claude Haiku 5.5** (опционально) | По нажатию «Выжимка», если включён пересказ отзывов | $0.10 за 1 млн входных и $0.50 за 1 млн выходных токенов — около $0.0003 за выжимку | Ключ — в секретах Worker, лимит расходов — в Anthropic Console |
| **Cloudflare Workers** | Каждый запрос сайта | Бесплатно до 100 000 запросов в день | — |

**Пример.** Неделя поездки: ~15 поисков в день (×4 = 60 Text Search) плюс ~5 нажатий «Искать ещё» (~20) и ~20 выжимок — за неделю ≈ 560 Text Search и ≈ 140 деталей. Это укладывается в ~1 000 бесплатных Text Search в месяц, если лимиты действуют для вашего аккаунта. При 40 поисках в день получится ≈ 1 100–1 300 Text Search в неделю, то есть около $5–10 сверх лимита. Платёжный аккаунт Google Cloud (карта) обязателен в любом случае.

## Защита от неожиданных расходов (обязательно)

1. **Google Cloud → APIs & Services → Quotas.** Поставьте дневные лимиты, например: Places API (New) Text Search ≤ 150 в день, Place Details ≤ 100 в день, Place Photos ≤ 100 в день (или 0, если миниатюры не нужны), Route Matrix ≤ 300 элементов в день. При превышении Google вернёт ошибку, и сайт покажет «Исчерпана дневная квота».
2. **Billing → Budgets & alerts.** Бюджет, например $5, с уведомлениями на 50/90/100 %.
3. **Ключ Google — только для нужных API.** В *API restrictions* оставьте Places API (New) и Routes API. Ключ серверный: не ставьте ограничение по HTTP referrer, потому что запросы идут от Worker, а не из браузера.
4. **Anthropic Console** (если включён пересказ) — отдельный ключ с месячным лимитом расходов.
5. В `wrangler.toml`: `ALLOWED_ORIGINS` — только ваш сайт; `RATE_*_PER_MIN` — мягкие лимиты на один IP.

## Развёртывание (≈15 минут)

```bash
cd worker
npm install
npx wrangler login                       # вход в аккаунт Cloudflare (бесплатный)
npx wrangler secret put GOOGLE_MAPS_KEY  # вставьте ключ Google (Places API (New) + Routes API)
npx wrangler deploy                      # выдаст адрес вида https://koyo-food-proxy.<account>.workers.dev
```

Затем на сайте откройте «🍜 Где поесть → Сервер поиска», вставьте адрес Worker и нажмите «Сохранить и проверить». Адрес можно и зафиксировать: впишите его в `site/food-config.js`. Это не секрет.

Проверка: `curl https://koyo-food-proxy.<account>.workers.dev/health` → `{"ok":true,"places":true,...}`.

## Выжимка и условия Google

* **По умолчанию** показываются официальная сводка отзывов Google (`reviewSummary`, «Summarized with Gemini») и описание места (`editorialSummary`) — так, как их отдаёт Google, с его пометкой и ссылкой на отзывы. Сводка доступна не для всех мест и регионов. Если её нет, сайт честно пишет об этом и даёт ссылку «Отзывы в Google Maps».
* **Пересказ отзывов через Claude** (`ALLOW_LLM_REVIEW_SUMMARY = "true"` + `wrangler secret put ANTHROPIC_API_KEY`) выключен намеренно. Условия Google Maps Platform ограничивают создание производного контента из данных Google, и пересказ отзывов может им противоречить. Включайте только если вы прочитали условия (<https://cloud.google.com/maps-platform/terms>) и согласны с риском. В этом режиме:
  * модель получает только те ≤ 5 отзывов, которые вернул Google, а сайт показывает размер выборки, даты и авторов;
  * модель — `claude-haiku-5-5` (самая дешёвая из актуальных), с инструкцией ничего не придумывать: минус считается, только если он встречается минимум в двух отзывах;
  * при меньше чем двух отзывах пересказ не делается.
* Сервер **ничего не хранит**. На сайте выжимка живёт только в памяти текущей вкладки, поэтому повторное раскрытие не делает новый платный запрос. Координаты пользователя округляются на телефоне до ~100 м и не сохраняются.
* Неофициальных скрейперов Google Maps нет — только официальный Places API.

## Тесты

```bash
cd worker && npm test   # имитация Google и Claude, без сети и без ключей
```

Диагностика на реальных данных: Actions → «Food search diagnostics» → Run workflow (поле `target` — название места). Скрипт `worker/diag/diagnose.mjs` печатает только число запросов, сколько мест найдено и на каком шаге нашлось искомое — без ключей и без координат пользователя.
